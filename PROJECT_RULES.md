# Правила проекта «Игра»

## Работа с изображениями и скриншотами

1. Изображения и скриншоты, присланные пользователем в чатах проекта, по умолчанию являются **референсами для обсуждения, анализа интерфейса и указания ошибок**.
2. **Не редактировать, не перерисовывать и не генерировать новые версии пользовательских изображений или скриншотов**, если пользователь прямо и однозначно не попросил создать или изменить изображение.
3. Если пользователь показывает скриншот интерфейса игры и просит что-либо «передвинуть», «добавить», «убрать», «исправить», «сделать» и т. п., это означает: **внести изменение в код игры в GitHub-репозитории**, а не изменить сам скриншот.
4. При работе над интерфейсом сначала изменяется рабочая версия игры (HTML/CSS/JavaScript и соответствующие модули), после чего пользователь проверяет результат через GitHub Pages.
5. Генерация или редактирование изображений выполняется только по отдельной явной просьбе пользователя, например: «нарисуй», «сгенерируй изображение», «измени эту картинку».

## Приоритет

Эти правила действуют во всех чатах проекта «Игра» и должны учитываться при дальнейшей разработке интерфейса и игрового прототипа.
