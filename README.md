# Game Live v2

Чистый старт мобильной игры-симулятора жизни. Репозиторий [Game-Live-Web](https://github.com/48s97j7ht5-ux/Game-Live-Web) остаётся архивом экспериментов с персонажем; здесь — только играбельный прототип.

## Что уже есть

- три экрана: **Мир**, **Телефон**, **Я**
- игровые часы и скорость времени
- локации двора, подъезда и квартиры
- каркас телефона и слоёв одежды

## Запуск

Откройте `index.html` через локальный сервер (модули ES не работают с `file://`):

```bash
python3 -m http.server 4173
```

Затем откройте http://localhost:4173

## Структура

```
index.html
css/          интерфейс
js/           логика экранов и состояние
```
