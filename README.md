# Game Live v2

Пока здесь только **станок персонажа v0**: с телефона можно запустить рендер и получить PNG.

## Как запустить с телефона

1. Открой репозиторий в приложении GitHub.
2. **Actions** → **Render character** → **Run workflow**.
3. Дождись зелёной галочки.
4. Смотри картинку в `factory/out/character.png` и в артефактах запуска.

v0 намеренно простой: болванка ¾, рост ~200 px, палитра персонажа до 48 цветов. Это проверка, что станок в репо живой, а не готовый герой из концепта.
